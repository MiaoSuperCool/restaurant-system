## 必须守住的 6 条

摘自《数据模型与角色权限设计》第三节。**动表结构前先看这 6 条**——它们都是事后返工代价极高的点：

1. 余额和积分**必须有流水账**，不能只存一个数字字段
2. 优惠券**拆两张表**：券模板 + 用户持券
3. 退款一律走**审批单**，线下退款也要补录、要留痕
4. 审计日志覆盖关键动作：改价、发券、退款、开停账号、登录、核销
5. 多店定价靠**门店菜品关联表**，别在菜品上写死价格
6. 与老系统共存靠**「同步记录 + 对账记录 + ID 映射」三件套**
